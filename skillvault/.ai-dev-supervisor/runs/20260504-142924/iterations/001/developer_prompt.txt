# Task Objective
Optimize the SkillVault login page UI to a modern, clean, professional enterprise SaaS login page.

## Allowed Changes
- Only modify: `frontend/src/views/LoginView.vue`
- You may adjust the **template structure** (HTML layout, element ordering, wrapper divs) and **scoped styles** (CSS inside `<style scoped>`).
- You may add/remove wrapper elements, restructure the card layout, adjust spacing, sizing, alignment, colors, typography, and responsive behavior.
- Desktop: card must be centered, moderate width (~400-440px max), comfortable whitespace.
- Mobile: no horizontal scroll, no overlap, no clipping. Use responsive breakpoints (e.g., `@media (max-width: 640px)`).
- Keep the overall visual style: modern, clean, professional enterprise SaaS login.

## Forbidden Changes
- Do NOT modify the `<script>` section at all.
- Do NOT change login logic, API calls, auth store, router, or i18n keys.
- Do NOT add new dependencies.
- Do NOT add new features (no registration, forgot password, third-party login, etc.).
- Do NOT remove or break existing bindings: `v-model`, `@click`, `:loading`, `:disabled`, `t(...)`, `changeLocale`, `handleLogin`, `locale`, `loginForm`, `loading`, `
