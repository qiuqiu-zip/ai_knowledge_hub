优化 SkillVault 登录页 UI，但不要修改任何业务逻辑。

当前目标是只对登录页做视觉优化，让页面看起来更现代、更干净、更像正式的企业级 SaaS / 后台系统登录页。请重点优化页面布局、背景、登录卡片、标题区域、语言选择器、用户名输入框、密码输入框、登录按钮、顶部提示条的视觉表现。

必须保留当前已有功能，包括语言切换、用户名输入、密码输入、登录按钮、登录提交逻辑、表单校验、接口调用、token/session/localStorage/cookie 处理、路由跳转、权限逻辑、国际化逻辑。不要修改这些业务逻辑。

不要新增注册、忘记密码、记住我、验证码、第三方登录、手机号登录、扫码登录、多因素认证、营销文案、插画模块、新接口、新字段或任何额外功能。

请先阅读当前登录页相关文件，确认项目使用的前端技术栈、登录页组件位置、样式文件位置、现有登录逻辑和语言切换逻辑。只允许修改登录页相关展示结构和样式。不要改其他页面，不要改后端，不要改认证逻辑，不要改路由逻辑，不要改状态管理逻辑。

设计方向：
1. 页面整体使用浅色、简洁、专业的背景，可以有轻微浅灰或浅蓝灰渐变，但不要花哨。
2. 登录卡片居中，宽度适中，圆角自然，阴影轻微，留白舒适。
3. 标题区保留 SkillVault 品牌感，可以使用“登录 SkillVault”作为主标题，并加一行简洁副标题。
4. 表单改成现代垂直布局，标签在输入框上方，输入框和按钮宽度统一。
5. 输入框高度、圆角、边框、hover、focus 状态要统一且精致。
6. 登录按钮使用蓝色主按钮风格，宽度铺满表单区域，hover/active/disabled/loading 状态要自然。
7. 语言选择器保留，但位置和样式要更协调，不能显得随便摆放。
8. 顶部提示条保留，但降低视觉干扰，让它像轻提示，不要抢登录卡片焦点。
9. 页面需要兼容桌面端和较小屏幕，不允许出现横向滚动、遮挡、错位或内容裁切。

严格限制：
1. 不允许修改登录接口。
2. 不允许修改表单提交逻辑。
3. 不允许修改用户名、密码字段绑定逻辑。
4. 不允许修改表单校验逻辑。
5. 不允许修改语言切换逻辑。
6. 不允许修改国际化 key 的含义。
7. 不允许修改路由跳转逻辑。
8. 不允许修改权限逻辑。
9. 不允许修改 token、session、cookie、localStorage 等认证相关逻辑。
10. 不允许引入新的 UI 框架或动效库。
11. 不允许重构项目结构。
12. 不允许修改与登录页无关的文件。
13. 不允许 commit，不允许 push。
14. 不允许输出或写入任何 secrets。
15. 不允许把 __pycache__、*.pyc、dist、node_modules、.env、.idea、.ai-dev-supervisor 纳入提交。

执行方式：
先只读分析登录页相关代码，确认应该修改哪些文件；然后做最小 UI 修改；最后输出真实改动说明和测试结果。

1. Summary of changes。
2. File-by-file explanation。
3. Test commands executed and results。
4. Risks and follow-up notes。
5. 明确说明登录接口、提交逻辑、语言切换、路由、权限、认证逻辑均未修改。
